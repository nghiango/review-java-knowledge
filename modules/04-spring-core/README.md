# Module 04 — Spring Core

Foundational Spring Framework IoC container architecture, dependency injection, bean lifecycle phases,
scopes, CGLIB/JDK dynamic proxies, Spring AOP self-invocation mechanics, and application event decoupling.

Study the canonical prose in [`docs/topics/spring-core/`](../../docs/topics/spring-core/).

```bash
./gradlew :modules:04-spring-core:test
./gradlew :modules:04-spring-core:compileBrokenExamples
./gradlew :modules:04-spring-core:compileExamples
```

This is a core container library module without a standalone web entry point.
