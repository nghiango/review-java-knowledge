In one of my previous projects, I influenced both the client and the technical lead to reconsider an operational design. Initially, operators were expected to access the database directly and execute stored procedures to modify data. I saw risks with this approach because it was difficult to control or audit unexpected database changes, and operators also had to use port forwarding to access the AWS-hosted database. I proposed an Excel-based command template uploaded through S3 instead. The backend validated the commands and executed only supported operations, so all changes went through application-level business rules rather than direct database access.
