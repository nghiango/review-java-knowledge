## Study loop

1. Read the concept.
2. Read the interview questions and answer before revealing the explanation.
3. Open the broken implementation.
4. Review it as a pull request and write down the issues.
5. Reveal the categorized issues.
6. Study the corrected implementation and trade-offs.
7. Run its tests.
8. Answer the senior follow-up questions.

## Two ways to learn

**Topic-first:** follow the [roadmap](roadmap.md) from Core Java to senior engineering.

**Problem-first:** choose an issue such as a race condition or resource leak in the
[issue catalogue](issues/index.md), then follow its links across technologies.
