# Java 25 & Spring Boot 4 Track: Spring MVC Delta

This module covers the modern Spring MVC delta in Spring Boot 4.0 / Spring Framework 7:
- **First-Class Framework API Versioning**: Declarative `@RequestMapping` version attributes and `ApiVersionResolver` resolving routes natively without custom reflection/interceptor hacks.
- **JSpecify Null-Safety Integration**: Modern `@NullMarked` and `@Nullable` type-use contracts across controller endpoints, models, and arguments replacing deprecated Spring `@NonNullApi`.
- **Modern Web Testing**: Spring 7 MVC testing patterns unifying mock and client testing.
- **Jackson 3 Readiness**: Record serialization contracts, immutability, and null handling.
